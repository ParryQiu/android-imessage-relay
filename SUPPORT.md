# Support

Use GitHub Discussions for setup and operational questions and GitHub Issues for reproducible defects. Include the release version, Android and macOS versions, the failing stage, and sanitized error codes.

Do not post phone numbers, SMS bodies, Access headers, Client Secrets, Tunnel tokens, private keys, Terraform state, live hostnames, account IDs, zone IDs, local usernames, or database files.

Security reports must use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).
